# Native clone checkpoint package

This payload preserves the tested native clone in an isolated source overlay. It does not replace the repository's existing native5 or league implementations. The parent integration supplies the repository README and build wrapper separately.

Included:

* `source`: the exact 50-file selected build source overlay, corresponding to source-r6/build-r6.
* `app`: frozen app-r3, including the original exported presentation meshes, pinned transform mapping, saved G1 control bindings, completion-aware pacing and CPU tests.
* `tools`: tools-r5, including build/launch helpers, native CLI identity validation, direct-control smoke and complete-match tests.
* `passive_support`: the later r2 passive tunnel/mirror source and tests. `--until-stop` explicitly removes the old four-hour expiration while retaining STOP, locks, resume and path/host-key checks. Paramiko is an optional Python dependency for these helpers.
* `dependency_source`: 27 historical translation units and 46 generated Warp CUDA kernel sources, copied read-only from Spark and checked against the existing dependency inventory. Its manifest preserves exact source paths, hashes, source attribution and object associations.
* `validation`: closed original-history/controller, match lifecycle/deactivation, graph comparison, dependency, connection repair, API and preexisting-checkpoint test source and evidence.
* `artifacts/native-clone-release-r1.zip`: the complete immutable release publication, including the actual ARM64 Linux CUDA evaluator and 282 indexed files. Every indexed file was verified against its publication size/hash after archive creation.
* `artifacts/native-clone-closed-validation-r1.zip`: the complete closed validation tree. This also preserves files that generic repository ignore rules may omit from the visible tree. Every archive entry was checked against its source bytes.

The release ZIP preserves historical bytes, including its older timed passive helper and four-hour README statement. The separate `passive_support` directory contains the current untimed repair. No files in the frozen release archive were rewritten.

Selected executable SHA256: `90a004a6aa89a72d13e1c44abe10f2adea70059c746075b062bedb442ed36b73`. It targets ARM64 Linux/NVIDIA SM121. It is not a Windows executable. CUDA graph replay remains disabled in the selected build; its closed comparison evidence is retained.

External dependencies remain necessary: pinned motor weights, native libraries, toolchain and historical compiled objects. The source inventory records provenance of the reused objects but does not establish a newly rebuilt complete header/toolchain closure. Machine paths in frozen receipts and build recipes require adaptation on another host. Saved control values are included; authentication profiles, SSH keys and login credentials are excluded.

NAS-only exclusions: live `live-session-r1` recordings, ongoing append logs/frame spools, active helper state/locks/STOP markers, raw human/evaluation capture collections, original authenticated Wine/Steam profiles, and external model weights/libraries/toolchain. They remain in their existing locations without modification. Closed synthetic oracle and diagnostic traces are included. No live game, viewer, helper or GPU process was changed by packaging.

Credential scans checked private-key, common token, JWT, literal bearer authorization and high-confidence password/secret assignment patterns in copied source/closed artifacts and expanded archive content. They found no such values. Email-shaped matches in executable bytes were shared-library symbol fragments, not complete account addresses. This is a bounded pattern scan, not an exhaustive guarantee. Machine names, local paths and private-network addresses remain as provenance, not credentials.

Full official-game parity is not established. This checkpoint preserves demonstrated original-function comparisons, API/match tests and remaining limitations; it makes no new training-performance or policy-strength claim.
