# Native human evaluation and policy league, 2026-09-14

## Delivered

The browser evaluator at `http://127.0.0.1:18768/` provides MuJoCo and
Puffysics, scripted and trained opponents, either human side, held input,
non-stacking attacks, points, falls, and within-backend policy rankings.
The earlier evaluator on port 18766 remains independent.

Human evaluation and tournaments use native CPU physics with CUDA controller
and policy inference. The new training attempt used native PufferLib 5.0
CUDA physics, learner inference, frozen-opponent inference, and PPO. No Python
interpreter or CPU physics was used in that new training attempt.

The native inference implementation matched the original learner exactly in
BF16 and FP32 tests. Both legacy MuJoCo checkpoints also matched their actual
older FP32 implementation, including its hidden activation and 64-tick RNN
reset. Greedy and sampled variants have separate immutable evaluation IDs.

## Observed matches

All fixtures used paired side assignments and seed 1, with an experimental
20-second official round clock. Actual physics duration includes reset pauses.
These are small preliminary samples, with unequal coverage between greedy
and sampled variants. They are not a complete all-variant round robin or
evidence of a superhuman policy.

not contribute to the paired ranking.

Policy actions contain no quit, leave, disconnect, reset, or backend switch.
Explicit policy-owned failures are forfeits; unknown infrastructure or physics
failures remain invalid trials. The league tests exercise both paths.

## New training and remaining blockers

Puffysics frozen-opponent smoke training completed one PPO epoch, 8,192
transitions, and produced a finite checkpoint. It is selectable as
`frozen-smoke-8k`. No completed rounds occurred during that short run.

The requested longer run targeted 1,048,576 transitions but aborted after
27 completed PPO epochs / 221,184 trained transitions. At rollout 28, arena
274 had invalid simulation state. Exit code was 134. The failed run does not
establish successful completed-run training SPS or final win rate.

The active rigid-body Puffysics path omits exported rotor armatures while
using the existing controller gains. A separate, opt-in articulated experiment
restored those inertias and improved early dynamics, but it also produced a
NaN in arena 1 at 2.41000056 seconds. It was not deployed or used for large
training. The failing operator still needs localization inside `rp_art_step`.
See [physics findings](../../native5/PHYSICS_BACKENDS.md) and the native5
validation directories for commands, hashes, timing, and failure evidence.

No new MuJoCo training run was launched. Its available GPU integration uses
Python orchestration, conflicting with the standing Python-free requirement.
The native C API implemented here is a CPU evaluation path and is explicitly
rejected by the trainer. A new MuJoCo GPU run requires either an authorized
Python-orchestration exception or implementation of a native GPU integration.

The older MuJoCo checkpoints had historical GPU training runs of 3,276,800
transitions each; the corrected run continued from the combined checkpoint.
Historical 82/128 wins used sampled actions and 120-second rounds. Those
results are not reused as current league strength.
